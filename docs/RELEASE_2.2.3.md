# JLU_schedule v2.2.3（Android）

Android 修复版，`versionCode=9`，最低支持 Android 8.0（API 26）。

## 本次修复

- **分段授课周次（#3）**：支持教务数据中的数字星期、离散周次、单双周和分段地点，保留不同教师各自的授课安排，避免在未开课的周次显示课程。
- **自定义背景（#4）**：恢复 Android 16 / HyperOS 3 的背景裁剪入口；取消或裁剪失败时保留原背景，保存失败会显示原因，旋转屏幕后可继续完成裁剪。
- **账号数据隔离（#2）**：成绩、绩点、考试和学业数据按实际登录账号保存；退出或切换账号会取消旧同步，迟到的响应不会写入新账号。网页登录和扫码登录也会隔离会话数据。
- **一键导入与工具同步（#2）**：修复导入提交和重试之间的竞争；原生登录触发页面重建后，正在进行的工具同步会在新账号上下文中继续一次，退出登录或切换网页会话则取消旧任务。

## 升级提示

- 如果旧版本已经导入了错误周次，请在升级后**重新导入课表并覆盖当前课表**，以教务系统原始数据修正安排。
- 首次升级后请**重新同步成绩、考试等工具数据**。旧工具缓存保留在本机；未能确认所属账号的缓存不会自动归入某个账号。
- 安装包沿用此前正式签名，可直接覆盖旧正式版并保留应用数据。

下载：[GitHub Release APK](https://github.com/JFyuhong/JLU_schedule/releases/download/v2.2.3/JLU_schedule.apk)。国内镜像的 HTTPS 入口目前仍无法从本机稳定访问；服务器清单和下载页同步更新，应用内下载继续使用 GitHub。

## 验证范围

- Android 单元测试覆盖周次解析、课表持久化、背景文件保存、账号隔离和同步重试。
- Android 16 模拟器验证背景裁剪与取消、屏幕旋转，以及原生登录后的同步恢复和退出取消。
- 尚未在 HyperOS 3 真机上复测背景裁剪，欢迎通过对应 issue 反馈结果。
